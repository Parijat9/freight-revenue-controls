# BI report setup

The tested browser report is generated by `python run.py`. This directory contains
Power Query, DAX and Tableau calculations for a native BI implementation. It is
not a validated PBIX or Tableau workbook. Native Desktop refresh has not been run.

## Power BI

Create a text parameter `DataFolder` pointing to `build`. Paste `import.pq` into
a blank query and name it `ShipmentFinance`. Create each measure in `measures.dax` separately.
Monetary measures are USD; percentages should display to one or two decimals.

## Tableau

Connect to `shipment_finance.csv` as a text file. Keep IDs as dimensions and numeric measures
as numbers. Add the named formulas from `tableau-calculations.txt` separately.
Use ratios of aggregated totals, not averages of row percentages.

## Report specification

Cards: delivered loads, potential billing gap, overdue balance. Bar chart: gap by lane. Matrix: customer, lane, finding and amounts. Slicers: lane, customer and finding. Keep the reporting cutoff visible.

Compare totals with `build/metrics.json` before publishing. Filters should reconcile
to the same source population. Do not join lane summaries back into detailed facts
and then sum the repeated lane totals. Keep forecasts separate from actual measures.
